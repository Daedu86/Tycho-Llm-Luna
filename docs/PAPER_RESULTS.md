# Paper Result Artifacts

`artifacts/evaluation_integrity.json` binds each reported policy to its canonical public-25 trace,
SHA-256 digest, official scorecard ID, and RHAE. `artifacts/appendix_metrics.json` contains the
per-game and aggregate metrics used by the paper. `artifacts/figure_data.json` is the compact source
for evaluation plots. Human-comparison tables use the released ARC-AGI-3 first-run human replays.
